AI 编程不是让工具一次替你写完产品。更可靠的起点，是把正在发生的一个小任务拆成输入、边界、改动和验收，然后亲自看见结果。

## 从什么问题开始

| 你现在遇到的事 | 先读 | 第一个可验收结果 |
| --- | --- | --- |
| 还没让 Agent 改过真实项目 | [最小 Agentic Coding 工作流](./minimum-agentic-coding-workflow/) | 一张任务卡、一个 diff、一次真实检查 |
| 需求只有一句自然语言 | [从自然语言到可运行 MVP](./natural-language-to-mvp/) | 输入、输出、失败态和验收条件 |
| 不确定该用 Claude Code 还是 Codex | [Claude Code 与 Codex 怎么选](./choose-claude-code-or-codex/) | 一张基于环境和风险的选择表 |

## 一条可复用的学习路线

1. 先把模糊想法写成一个可验证的小任务，而不是要求工具“做一个完整应用”。
2. 让 Agent 读取现有项目、提出计划、交回最小改动，并保留它实际执行过的检查。
3. 对照 [项目交付检查表](./project-checklist/) 看 diff、测试和未覆盖的边界，再决定是否进入下一轮。

## 读完要留下什么

- 一份写清输入、输出、范围与验收的任务卡。
- 一次你亲自审过的代码 diff 和命令输出。
- 一个能在下次任务继续使用的失败记录或项目规则。
